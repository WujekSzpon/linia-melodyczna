# Linia Melodyczna od Wujka Szpona

Interaktywny konspekt opracowań melodii. Dane są pobierane z pliku KONSPEKT - MELODIA.xlsx, a okładki znajdują się w katalogu okladki.

Strona: https://wujekszpon.github.io/linia-melodyczna/

## Najczęściej aktualizowane pliki

- KONSPEKT - MELODIA.xlsx - baza utworów i linków,
- okladki/ - okładki przypisane do pozycji w arkuszu,
- index.html - kod konspektu.
